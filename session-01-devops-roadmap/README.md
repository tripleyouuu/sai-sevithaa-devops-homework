# Session 1: DevOps Engineer Roadmap

Orientation session — no hands-on homework was assigned for Session 1 (the
original homework document starts directly with Session 2's Linux tasks).
Session 1's own material, from the course's `devops-heros` repo, is a slide
deck (`devops1-83.pdf`, 83 slides) walking through what a DevOps engineer
role covers and the learning path the rest of the course follows: Linux and
shell fundamentals → networking → Git → containers (Docker) → orchestration
(Kubernetes, Helm) → CI/CD and DevSecOps → infrastructure as code (Terraform,
AWS) → monitoring, observability, and GitOps — which maps directly onto
Sessions 2–20 of this repo.

No deliverable required for this session beyond reviewing that roadmap.
